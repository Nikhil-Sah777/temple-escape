# Temple Escape

A browser puzzle game where you open the doors of an ancient temple by solving riddles and code puzzles before time runs out.

**Play it here: https://nikhil-sah777.github.io/temple-escape/**

## Features
- Two modes: general riddles, and code puzzles in Python, C, C++ and Java
- Three difficulty levels: Easy, Medium and Hard
- Time per door: Relaxed (40s), Normal (25s), Pressure (15s), Custom, or Practice with no timer
- Three lives, a timer bar showing the time left, and hints
- Choose how many questions to play (presets, a custom slider, or endless mode)
- An explanation after every answer
- Daily challenge with the same puzzles for everyone that day
- Sound themes: Temple, Chimes, Arcade, Zen, or Off
- Ending screen with a rank, score, accuracy and best streak, plus a button to copy your result

## Built with
HTML, CSS and JavaScript only, with no libraries. The sounds are generated in the browser.

## Run it on your computer
Download `index.html` and open it in any browser.

## What I learned
Planning a game in stages, building the timer and lives logic, generating puzzles with code, and publishing a site with GitHub Pages.
